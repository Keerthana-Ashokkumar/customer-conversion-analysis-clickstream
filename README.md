# Customer-Conversion-Analysis-Using-Clickstream-Data

Customer Conversion Analysis for Online Shopping Using Clickstream Data

## 📌 Project Overview

This project is designed to analyze online shopping clickstream data and build machine learning models to understand customer browsing behavior. The system predicts whether a customer will complete a purchase, estimates potential revenue, and segments customers based on their online behavior.

An interactive Streamlit application is developed to provide real-time predictions and customer insights.

---

## 🏫 Domain

E-commerce and Retail Analytics

---

## ❓ Problem Statement

E-commerce businesses generate large amounts of customer clickstream data through online browsing activities. Understanding this behavior can help businesses identify potential buyers, estimate customer revenue, and create meaningful customer segments.

This project uses clickstream data and machine learning techniques to automate customer conversion prediction, revenue estimation, and customer segmentation.

---

## 💼 Business Use Cases

• Predict customers who are likely to complete a purchase
• Identify potential buyers for targeted marketing campaigns
• Estimate potential revenue from customer browsing behavior
• Segment customers based on their online shopping patterns
• Identify users who may abandon their shopping journey
• Improve personalized product recommendations

---

## 📊 Dataset Description

The project uses clickstream data containing information about customer browsing sessions and product interactions.

### Important Features

| Feature           | Description                                                   |
| ----------------- | ------------------------------------------------------------- |
| YEAR              | Year of the browsing activity                                 |
| MONTH             | Month of the browsing activity                                |
| DAY               | Day information                                               |
| ORDER             | Sequence of clicks during a session                           |
| COUNTRY           | Country of origin of the user                                 |
| SESSION ID        | Unique browsing session identifier                            |
| PAGE 1            | Main product category                                         |
| PAGE 2            | Clothing/product model                                        |
| COLOUR            | Product colour                                                |
| LOCATION          | Product image location on the webpage                         |
| MODEL PHOTOGRAPHY | Product image type                                            |
| PRICE             | Product price in US dollars                                   |
| PRICE 2           | Indicates whether the product price is above category average |
| PAGE              | Page number within the e-store website                        |

Dataset Source: UCI Machine Learning Repository – Clickstream Data

## 🔍 Approach

### 1. Data Preprocessing

• Load and inspect the clickstream dataset
• Handle missing values
• Clean and prepare the data
• Encode categorical variables
• Scale numerical features where required

### 2. Exploratory Data Analysis

• Analyze customer browsing behavior
• Study session and click patterns
• Analyze product and price-related features
• Perform correlation analysis
• Create visualizations to understand the dataset

### 3. Feature Engineering

• Create meaningful customer/session-level features
• Analyze clickstream patterns
• Generate behavioral metrics
• Prepare features for machine learning models

### 4. Target Creation & Data Preparation

• Create the target variable for customer conversion
• Prepare classification and regression datasets
• Prepare data for customer segmentation
• Split data for model training and evaluation

### 5. Model Building

The project includes three machine learning tasks:

**Classification**

Predict whether a customer will complete a purchase.

Models include:
• Logistic Regression
• Decision Tree
• Random Forest
• XGBoost
• Neural Network

**Regression**

Estimate the potential revenue generated by a customer.

Models include:
• Linear Regression
• Ridge Regression
• Lasso Regression
• Gradient Boosting Regressor

**Clustering**

Segment customers based on their online browsing behavior.

Models include:
• K-Means
• DBSCAN
• Hierarchical Clustering

### 6. Model Evaluation & Tuning

Classification models are evaluated using:

• Accuracy
• Precision
• Recall
• F1-Score
• ROC-AUC

Regression models are evaluated using:

• MAE
• MSE
• RMSE
• R² Score

Clustering models are evaluated using:

• Silhouette Score
• Davies-Bouldin Index
• Within-Cluster Sum of Squares

### 7. Class Balancing

The classification dataset is checked for class imbalance.

Balancing techniques include:

• SMOTE
• Undersampling
• Class Weight Adjustment
